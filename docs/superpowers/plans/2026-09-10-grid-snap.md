# Desktop Widgets: Grid snapping — Implementation Plan

**Spec:** `docs/superpowers/specs/2026-09-10-round2-design.md` §1.

**Architecture:** top-level `grid` setting (`Registry.gridOf` / `grid_of` normalise; `settingsOf` / `settings_of` carry every non-widget top-level key through `write`, `preset apply` and the service's `saveDoc`). `Arrange.snapPlace(place, size)` snaps corner offsets; the service applies it in `commitPlace` and the overlay applies it to the live override. Overlay draws a dot grid (one Text) and takes `G` / `[` / `]`; editor header has a Grid button; IPC `desktop-widgets grid <value>`; CLI `grid`.
