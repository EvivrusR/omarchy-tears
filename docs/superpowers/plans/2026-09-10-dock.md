# Desktop Widgets: Launcher dock — Implementation Plan

**Spec:** `docs/superpowers/specs/2026-09-10-round2-design.md` §4 (Michael: wallpaper-layer dock, never reserves space).

**Architecture:** `dock` registry type declares `input: true` (the service leaves its window mask unset, so it takes clicks where no window covers it) and per-type `defaults` for common keys (`corner: bottom-center`, `y: 24`, `backdrop: 0.5`) — `fieldsFor` in all three engines merges these into the common field copies so defaults, validation, editor and CLI help agree. New corners `top-center` / `bottom-center` anchor neither side, which layer-shell centres (`Arrange.rectFor` mirrors it). `apps` is a new field type (list of desktop-entry ids): validated in JS + Python, parsed from `a,b,c` on the CLI, picked in the editor with a searchable MultiSelect over `DesktopEntries` minus Omarchy's `launcher.hides`. `desktop-widgets apps` lists ids from the XDG dirs. Launch = `uwsm-app -- gtk-launch <id>.desktop`.
